# IntegrityLens demo (static prototype)
Open `index.html` in a browser (or use the VSCode Live Server extension). No install, no backend. All data is invented.

Flow: 1 Upload (files mapped to students, language detected) → 2 Batch results (one report per student) →
3 Student report (AI-text analysis + checks of references, links, figures, calculations) → 4 Release & contest
(instructor approves, reports are "sent" to each student, student can contest).
